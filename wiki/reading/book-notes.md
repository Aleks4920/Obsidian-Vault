# Book Notes

Notes and summaries for books read. Tracked in the Notion Book Notes database. Part of [[reading]].

## Database Schema
Each book note entry has:
- **Name** — Book title
- **Author** — Author name
- **Tags** — Category (Book, Technology, Self-Improvement, Motivational, Negotiation Techniques, etc.)
- **Created / Last Updated** — Timestamps

## Views in Notion
- **All Docs** — Full list sorted by last updated
- **By Owner** — Board view grouped by author
- **By Type** — Board view grouped by tag/category
