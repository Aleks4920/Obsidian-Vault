# Obsidian-Vault

Personal Obsidian vault used for notes, research, and knowledge management.

## Structure

wiki/ — main body of notes
raw-sources/ — raw/reference source material
.obsidian/ — Obsidian app configuration (themes, plugins, workspace layout)
CLAUDE.md — operating notes for AI-assisted vault management

## Usage

Open this folder as a vault in Obsidian (https://obsidian.md/). Notes are written in Markdown and linked with [[wikilinks]].

This is a personal knowledge base rather than a software project, so its contents change frequently as notes are added, edited, and reorganized.
