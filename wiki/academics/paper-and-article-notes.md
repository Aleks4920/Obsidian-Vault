## MalBERTv2: Code Aware BERT-Based Model for Malware Identification

**Authors:** Abir Rahali, Moulay A. Akhloufi  
**Topic:** Malware detection using pre-trained language models  
**Related:** [[cybersecurity-notes]], [[devsecops]]

### Summary

MalBERTv2 is an improved malware detection model that uses a code-aware pre-trained language model (based on BERT) to classify Malware/Goodware (MG) samples.

### Key Contributions

1. **MalBERTv2 model** — An improved version of MalBERT, building a full pipeline for code-aware pre-trained language model for MG detection
2. **Pre-tokenization process** — A novel approach to feature representation for malware code
3. **Extensive evaluation** — Experiments on a variety of datasets collected from public resources

### Key Idea

Uses BERT-style language modeling applied to malware code rather than natural language. The model learns code-level patterns that distinguish malicious from benign software — a novel application of NLP techniques to cybersecurity.
