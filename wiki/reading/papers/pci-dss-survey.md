# A Survey of Payment Card Industry Data Security Standard (PCI DSS)

**Authors:** Jing Liu, Yang Xiao  
**Topic:** Survey of PCI DSS compliance requirements and practices  
**Related:** [[cybersecurity-notes]], [[devsecops]]

**PCI DSS** is the Payment Card Industry Data Security Standard, a set of security requirements for organizations that handle credit card data. Key areas include network security, cardholder data protection, vulnerability management, access control, monitoring, and security policies.
